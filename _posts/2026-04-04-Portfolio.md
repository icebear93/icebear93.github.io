## 1. 통합 데이터 분석 플랫폼 구축 (에스디바이오센서)

**기간**: 2024.11 – 현재 &nbsp;|&nbsp; **역할**: 단독 설계·구현·운영

### 배경

CGM(연속혈당측정기) 센서 개발 조직에서 데이터 분석은 팀원 각자가 로컬 환경에서 개별적으로 수행하고 있었습니다. 동물 실험, 사람 임상, 실험실(in vitro) 데이터가 분산되어 있었고, 표준화된 평가 환경이 없어 분석 결과의 일관성과 재현성이 낮았습니다. 유료 분석 소프트웨어 도입을 검토했으나 센서 도메인에 특화된 기능이 부족하고 비용 문제가 있었습니다.

### 문제 정의

> "팀 전원이 동일한 기준과 환경에서 실시간으로 데이터를 분석하고, 결과를 공유할 수 있는 통합 플랫폼이 필요하다."

### 설계 및 구현

**① 데이터 인프라 구축**
- PostgreSQL 데이터베이스를 설계하여 동물·임상·in vitro 데이터를 중앙 저장
- 웹 크롤러와 스케줄러를 결합한 외부 데이터 자동 수집·DB 저장 파이프라인 구축
- 워크스테이션을 서버로 구성하여 사내망 내 웹앱 배포 환경 구축

**② Streamlit 기반 올인원 분석 대시보드 개발**

초기에는 DB에서 데이터를 불러와 시각화하는 툴로 시작하였으나, 지속적으로 기능을 추가하여 현재는 아래를 모두 하나의 웹앱에서 처리합니다.

| 기능 영역 | 세부 내용 |
|---|---|
| 데이터 통합 | 동물·임상·in vitro 데이터 timeline 정렬 및 시간축 align |
| 품질 평가 | 데이터 품질, 배터리 구동 상태, 노이즈 평가 (자체 수립 기준 적용) |
| 알고리즘 평가 | 알고리즘 적용 결과, 예측 모델 성능 평가 |
| 정확도 지표 | MARD, PARD, CEG(Clarke Error Grid), FDA iCGM 기준 평가 |
| 시계열 분석 | time lag 평가, 신호 노이즈 분석 |

**③ 실험 관리 앱 개발 (Lab Test Tracker)**
- 테스트 센서 정보, 실험 장비 정보, 실험 진행 상황을 추적하는 앱을 독자 개발
- 팀 전원이 실험 추적 목적으로 현재 활용 중

**④ 혈당 분석 AI 챗봇 개발**
- AWS 클라우드 환경에서 사용자 질의에 따라 혈당 데이터 분석 및 인사이트를 제공하는 에이전트형 챗봇 개발 (외부 협력사 NDS와 공동 진행)

### 기술 스택

`Python` `PostgreSQL` `Streamlit` `Plotly` `Pandas` `NumPy` `AWS` `Git`

### 성과 및 임팩트

- **팀 전원이 단일 플랫폼으로 분석** — 분산된 로컬 분석 환경을 통합하여 분석 일관성·재현성 확보
- **유료 분석 소프트웨어 대체** — 도메인에 특화된 기능을 직접 구현하여 비용 절감 및 커스터마이징 자유도 확보
- **의사결정 속도 향상** — 실시간 대시보드를 통해 실험 결과를 즉시 분석·공유 가능

> **HR 직무 연결점**: Employee Life Cycle 전반에 걸친 HR 데이터 파이프라인 구축, BI Tool 개발·운영 경험과 직접 대응

## 2. 센서 품질평가 체계 수립 및 경쟁사 비교 분석 (에스디바이오센서)

**기간**: 2024.11 – 현재 &nbsp;|&nbsp; **역할**: 기준 수립·실험 설계·분석·결과 공유 전담

### 배경

자사 CGM 센서 개발 초기 단계에서 "우리 센서가 어느 수준인가"를 판단할 객관적 기준이 사내에 전혀 없었습니다. 센서 조성(composition)도 여러 후보가 있었고 어느 방향으로 개발을 이어갈지 결정이 필요한 상황이었습니다.

### 문제 정의

> "자사 센서의 정확도·특성을 객관적으로 평가할 기준 자체가 없다. 기준을 먼저 만들고, 경쟁사와의 비교를 통해 현 수준과 개선 방향을 파악해야 한다."

### 접근 방법

**① 평가 기준 수립 (사내 최초)**
- 기존에 품질 평가 기준이 전무한 상황에서 FDA iCGM 가이드라인 및 CEG(Clarke Error Grid) 평가 체계를 논문·공식 문서 분석을 통해 도입
- 데이터 전처리 전략 및 노이즈 평가 기준도 자체 수립

**② 비교 실험 환경 구축**
- 경쟁사 센서와 자사 센서를 동일 실험 환경에서 동시 측정하기 위한 실험 장치를 직접 설계
- 안정적이고 신뢰할 수 있는 데이터 수집 프로토콜 구축 → 실험 재현성 확보

**③ 시계열 데이터 비교 분석**
- RMSE, 정확도 지표(MARD 등)를 활용하여 time lag, 초기 드리프트 패턴, 온도에 따른 반응 특성을 정량적으로 비교
- 온도가 센서 반응에 미치는 영향을 파악하기 위해 저온에서 37도까지 온도를 단계적으로 변화시키는 추가 실험 설계·수행

**④ 인사이트 도출 및 전파**
- 초기 드리프트 알고리즘 개선 시 정확도 향상 여지 발견
- time lag 지표에서 현재 예측 알고리즘이 정상 작동하고 있음을 확인
- 온도에 따른 드리프트 변화 패턴 발견 → 온도 보정 알고리즘 추가 필요성 도출
- 여러 센서 조성 중 현재 버전을 기준으로 개발을 이어가야 한다는 결론 도출

### 기술 스택

`Python` `Pandas` `NumPy` `Plotly` `Matplotlib` `RMSE / MARD / CEG / iCGM`

### 성과 및 조직적 임팩트

- **전 부서 의사결정 지원**: 분석 결과를 AI팀에 국한하지 않고 센서 제조팀, 소프트웨어 제어팀 등 전 협업 부서에 공유하여 각 파트의 개발 방향 의사결정에 인사이트를 제공, 실제 공정 및 알고리즘 개선으로 이어짐
- **사내 혁신 아이디어 경연 최우수상** 수상 (AI 파트 아이디어 제안)

> **HR 직무 연결점**: "기준 없는 상황에서 먼저 기준을 만들고 조직을 움직이는" 역량 — HR 데이터 거버넌스 수립, 분석 역량 조직 내 전파와 동일한 구조

## 3. 혈당·저혈당 예측 알고리즘 개발 (에스디바이오센서)

**기간**: 2024.11 – 현재 &nbsp;|&nbsp; **역할**: 알고리즘 독자 설계·구현·검증

### 배경

CGM 센서의 핵심 가치 중 하나는 현재 혈당을 측정하는 것을 넘어 미래 혈당을 예측하고 저혈당을 사전에 경고하는 것입니다. 기존 논문에서 다양한 접근법이 제안되어 있으나, 자사 센서의 특성에 맞는 알고리즘을 직접 설계·검증할 필요가 있었습니다.

### 구현 내용

**① 30분 후 혈당 예측 모델**
- 기존 CGM 관련 논문의 알고리즘 분석 및 자사 센서 데이터에 맞는 시계열 예측 모델 개발
- 다양한 AI 모델(LSTM, Transformer 계열 등)을 확보된 시계열 데이터에 적용하여 성능 비교 평가

**② 15분 후 저혈당 확률 예측 모델**
- 저혈당 사전 경고를 위한 확률 예측 모델 독자 설계
- 임계값 설정 및 알림 로직 설계·검증

**③ 최신 기술 동향 분석**
- CGM 관련 최신 AI 논문 및 경쟁사 제품 동향을 주기적으로 분석·보고
- 서울대학교와의 혈당 알고리즘 관련 외부 연구 협업 과제 참여

### 기술 스택

`Python` `TensorFlow` `PyTorch` `Scikit-learn` `Pandas` `NumPy` `시계열 예측 모델`

### 성과

- 자사 센서 특성에 최적화된 예측 알고리즘 확보
- 외부 학술 기관(서울대)과의 협업을 통한 알고리즘 고도화 진행 중

## 4. AX TFT — 전사 AI 거버넌스 수립 (에스디바이오센서)

**기간**: 2024.11 – 현재 &nbsp;|&nbsp; **역할**: AX TFT 구성원, HR팀 협업

### 배경

조직 내 AI 활용에 대한 관심이 높아졌으나, 어떤 AI 도구를 어떻게 도입하고, 데이터 보안·민감도를 어떻게 관리하며, 직원들의 참여를 어떻게 유도할지에 대한 기준이 전혀 없는 상태였습니다.

### 문제 정의 및 접근

> "AI 도입을 원하는 부서들이 있지만, 기준이 없으면 제각각으로 움직인다. 먼저 규정 초안을 만들고 조직이 공통된 방향으로 움직이도록 틀을 잡아야 한다."

센서 품질평가 체계 수립과 동일한 방식으로 접근했습니다. 기준이 없는 상황에서 먼저 초안을 제시하고, 각 부서의 계획을 검토하며 개선하는 방식으로 거버넌스를 구축하였습니다.

### 주요 역할 및 성과

| 역할 | 내용 |
|---|---|
| 정책 수립 | '사내 AI 개발 관리 규정' 초안 수립, AI 효율·생산성 증진을 위한 도입 가이드라인 제정 |
| 거버넌스 운영 | 각 부서 제출 AI 도입 계획서 검토, 데이터 보안·민감도 평가, 효율적 AI 활용 방안 제시 |
| 보상제도 설계 | AI 활용 성과 연동 보상 체계를 HR팀과 협업하여 설계 |
| 교육 운영 | AI 교육 커리큘럼을 HR팀과 공동 개발 및 운영 |

> **HR 직무 연결점**: HR AX 추진, AI 기반 HR 전략 수립, 데이터 분석 역량 조직 내 전파 업무와 직접 대응. HR팀과의 협업 경험 보유.

## 5. 위기인식지수 AI 경보 시스템 구축 (한국리스크관리, 단독 프로젝트)

**기간**: 2024.03 – 2024.10 &nbsp;|&nbsp; **역할**: 기획·설계·개발·검증 전 단계 단독 수행 (3주 완수)

### 배경

시장 경기 침체를 사전에 감지하는 위기인식지수를 AI로 예측하는 시스템 도입이 필요했습니다. 해당 프로젝트는 별도 팀 구성 없이 단독으로 수행하였습니다.

### 문제 정의 및 접근

**① 데이터 확보 문제**
- 위기인식지수 예측에 활용 가능한 시계열 데이터 수집 및 검증
- 데이터 부족 및 노이즈 문제를 전처리 전략으로 해결

**② 모델 설계 및 비교 평가**
- 시계열 예측에 적합한 다양한 모델(TensorFlow, PyTorch, Scikit-learn, darts 활용)을 구현하고 성능 비교
- 최신 논문을 직접 참고하여 접근 방법 개선

**③ 단계별 문제 해결**
- 초기 분석 접근 방법 자체가 막히는 상황에서 일정에 맞는 계획을 수립하고 단계별로 해결
- 3주 내 의미 있는 AI 모델 완성

### 기술 스택

`Python` `TensorFlow` `PyTorch` `Scikit-learn` `darts` `Pandas` `NumPy` `Matplotlib` `Seaborn` `Plotly`

### 성과

- 단독으로 프로젝트 전 과정(기획~검증)을 3주 만에 완수
- 시장 경기 침체를 사전 감지하는 예측 시스템 구축

> **HR 직무 연결점**: 데이터 분석 과제 기획부터 통계 기반 예측 시뮬레이션, 인사이트 도출까지의 전 과정 경험
